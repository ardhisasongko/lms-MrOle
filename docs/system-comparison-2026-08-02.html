Metodologi

Cara membaca persentase

  • Sepuluh domain diberi bobot sama agar satu keberhasilan besar tidak menutupi debt di domain lain.
  • Skor meningkat hanya jika ada bukti repository, migration remote, test, build/lint, independent review, atau probe produksi.
  • Rentang interpretasi: 0–39 rapuh, 40–59 dasar, 60–79 terkendali sebagian, 80–94 kuat, 95–100 sangat matang.
  • Skor ini bukan SLA, coverage statement, penetration test, atau hasil Lighthouse terbaru.
